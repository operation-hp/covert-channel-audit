# covert-channel-audit
# Audit and Security Checklist for AI-Agent and Vibe-Coding Covert Channels

This repository is a community-driven effort to document audit practices, security controls, detection ideas, and governance checklists for covert channels created or enabled by AI agents, AI-assisted development, and vibe coding workflows. This project focuses on the defensive side: helping security teams, auditors, engineering leaders, and governance teams understand where covert channels may appear and how to reduce the associated risks. 



## Why This Matters

Examples of emerging risk areas include:

- QR codes or generated images used to move sensitive data
- AI-generated scripts that bypass normal data handling workflows
- Agent-to-agent communication paths that are not logged or reviewed
- Browser automation that copies, transforms, or exports sensitive data
- Prompt-based workflows that convert regulated data into seemingly harmless formats
- Generated files, diagrams, markdown, logs, screenshots, or documents used as data carriers
- Vibe-coded internal tools that lack authentication, logging, review, or data controls

Many existing security controls were designed for files, emails, endpoints, and APIs. They may not fully account for AI-generated content, agentic workflows, or human-in-the-loop data transformation.

## Scope

This repository will focus on audit and security checklists for:

- AI agents and autonomous workflows
- AI-assisted coding and vibe-coded applications
- Data loss prevention gaps involving AI-generated content
- Covert channels using images, QR codes, documents, logs, prompts, metadata, and generated code
- Security review questions for AI-enabled development
- Detection and monitoring considerations
- Governance, policy, and training recommendations
- Risk assessment templates for security and audit teams


## Intended Audience

This repository is intended for:

- Security architects
- CISOs and security leaders
- Internal audit teams
- GRC professionals
- AI governance teams
- Application security engineers
- Detection engineering teams
- Enterprise architects
- Developers building with AI agents and coding assistants

## Responsible Use

This project exists to improve security awareness and defensive readiness. Please do not submit exploit code, instructions for bypassing controls, or detailed covert-channel construction techniques.

When discussing risks, focus on detection, prevention, governance, and auditability.
